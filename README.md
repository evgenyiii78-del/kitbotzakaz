# @zakazKiT_bot — уведомления о новых заказах Flowwow Seller

**Назначение:** только чтение заказов Flowwow и отправка уведомлений в Telegram. Бот не принимает и не отменяет заказы.

## Развёртывание на Bothost

1. Подключите этот GitHub-репозиторий в Bothost как Python-проект. Главный файл: `main.py`, зависимости: `requirements.txt`.
2. Подключите существующего Telegram-бота **@zakazKiT_bot**. Токен получите в @BotFather. Если бот уже запущен на Bothost, замените существующее развёртывание — не запускайте два процесса с одним токеном.
3. В разделе «Переменные окружения» добавьте:
   - `FLOWWOW_TOKEN` — токен Flowwow API из кабинета продавца. Не публикуйте его.
   - `BOT_TOKEN` — токен Telegram. Если Bothost сам задаёт переменную, повторять не нужно.
   - `SETUP_CODE` — придуманный вами секретный код длиной **не менее 8 символов**.
   - `DATABASE_PATH` — `/app/data/flowwow_orders.db`.
   - `POLL_SECONDS` — `60` (по умолчанию; при ограничениях API увеличьте).
   - `LOOKBACK_DAYS` — `2` (от 1 до 7 дней, по умолчанию 2).
4. Запустите бот. В Telegram откройте https://t.me/zakazKiT_bot, нажмите «Старт» и отправьте `/connect ВАШ_КОД`.
5. Проверьте `/test` (тест Telegram), `/status` (состояние) и `/last` (последний сохранённый заказ). После первой успешной проверки Flowwow бот сообщит, что мониторинг подключён.

## Как работают уведомления

- Бот опрашивает API Flowwow каждые 60 секунд и проверяет активные магазины.
- При первой синхронизации уже созданные заказы помечаются как известные, без отправки старых уведомлений.
- Команда `/last` вручную показывает самый свежий заказ из локальной базы, полученной из Flowwow. Это не повторное уведомление и не новый API-запрос; данные обновляются при очередной проверке, обычно раз в 60 секунд.
- При появлении нового ID заказа отправляет сообщение с товарами, датой, стоимостью и комментариями, если поля есть в API.
- Защита от повторов и непрочитанные уведомления хранятся в SQLite. База должна находиться в постоянной папке `/app/data`.
- При сбое Telegram отправка повторяется при следующей проверке. При длительном простое заказы старше окна `LOOKBACK_DAYS` могут не обнаружиться.
- Бот не изменяет статусы заказов и ничего не подтверждает в кабинете Flowwow.

## Используемый API

- `POST https://apis.flowwow.com/apiseller/shops` — получить ID активных магазинов.
- `GET https://apis.flowwow.com/apiseller/orders/list?shopId=...&createdDate=YYYY-MM-DD&limit=100` — получить список заказов.
- Аутентификация: HTTP-заголовок `Authorization: Bearer <FLOWWOW_TOKEN>`.

**Важно:** проект проверен на синтаксис и смоделированных заказах, но реальное подключение к Flowwow с вашим токеном требует проверки после развёртывания.

## Безопасность

- Ни Flowwow-токен, ни Telegram-токен не должны попадать в GitHub. Используйте секретные переменные Bothost.
- Не загружайте файл `.env` и базу `.db` в публичный репозиторий — они исключены через `.gitignore`.
- Привязка чата разрешена только через `SETUP_CODE` в личных сообщениях.
- Один токен Telegram должен обслуживать только один запущенный экземпляр бота.

## Локальный запуск

Требуется Python 3.10+.

```bash
python -m pip install -r requirements.txt
python main.py
```

Предварительно задайте переменные окружения, указанные в `.env.example`. Сам файл `.env.example` — это образец, он автоматически не загружается.
